## 📖 About the Project

**Student Buddy** is a student-focused productivity application that combines a focus timer and task management system into one simple interface.

The application is designed to help students improve concentration, organize study activities, and develop productive study habits.

With a clean and minimal user interface, Student Buddy provides essential productivity tools without unnecessary distractions.

### 🎯 Project Objectives

- Improve student productivity and time management.
- Encourage focused and distraction-free study sessions.
- Simplify daily task organization.
- Provide an easy-to-use productivity interface.
- Combine essential study tools in one application.

---

## ✨ Features

### ⏱️ 1. Focus Timer

Stay productive by dedicating specific time intervals to studying.

**Features:**

- Select a study session duration.
- Default focus duration of 30 minutes.
- Start a focus session.
- Reset the timer when needed.
- Large and readable timer display.
- Simple controls for managing study sessions.

### 📝 2. Task Manager

Organize your study activities and keep track of important tasks.

**Features:**

- Add new tasks.
- Quickly organize study activities.
- Simple task input interface.
- Minimal and distraction-free design.

### 🎨 3. Clean User Interface

Student Buddy provides a modern and easy-to-use interface.

**Highlights:**

- Compact layout.
- Simple navigation.
- Clear visual hierarchy.
- Easy-to-access controls.
- Student-friendly design.

## 🚀 Getting Started

Follow these steps to run Student Buddy locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/DELTA-45-G/student-buddy-extension.git
```

### 2. Navigate to the Project Directory

```bash
cd student-buddy-extension
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Open the local URL displayed in your terminal.

For a default Vite configuration, this is typically:

```text
http://localhost:5173/
```

## 📚 How to Use

### ⏱️ Focus Timer

1. Open Student Buddy.
2. Navigate to the Focus Timer section.
3. Select your preferred study duration.
4. Click **Start** to begin the timer.
5. Focus on your study session.
6. Click **Reset** to reset the timer.

### 📝 Task Manager

1. Navigate to the Tasks section.
2. Enter a task in the input field.
3. Click the **+** button.
4. Add additional tasks as required.
5. Use the task section to organize your study activities.
